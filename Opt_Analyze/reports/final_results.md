# 优化效果科学测量结果

## 实验设计

**基线**: `reexport_plain`（原始ONNX用当前ATC重新编译）→ 排除编译链路差异
**噪声标定**: 同一OM跑10轮 → 量化环境噪声
**优化测量**: 每变体 vs 基线随机交错6轮 → 统计检验（t检验，α=0.05）

## 每种优化的因果解释

### 1. fp16 (-10.51% MobileNet, -1.05% ResNet50) ✅ 唯一有效优化

**ONNX变化**: 权重从fp32→fp16（文件大小减半），**图结构不变**
**OM变化**: fp16.om (7,660,272 bytes) ≈ 原始AIPP OM (7,660,559 bytes) ≈ 7.66MB
**因果链**: 
- 权重精度降低 → 参数带宽需求减半 → 数据搬运压力降低
- MobileNet受益更大(-10.5%)：因为它本身就偏带宽瓶颈（分析报告显示带宽利用率83%）
- ResNet50受益较小(-1.05%)：因为它的瓶颈在大特征图搬运而非参数加载
- **关键巧合**: fp16 OM大小与原始AIPP OM几乎相同，说明历史基线就是在类似精度模式下编译的

### 2. shape_inferred (MobileNet -3.86%, ResNet50 +1.79% ❌)

**ONNX变化**: 嵌入完整shape信息，文件大小+0.01~0.12%
**OM变化**: 大小与reexport_plain相同（7.77MB / 51.68MB）
**因果链**:
- ONNX中补全了所有中间张量的静态shape信息
- ATC编译器获得更多信息后可能改变了优化策略
- **ResNet50显著变慢(+1.79%, p=0.044)**: 推测ATC由于shape完整而选择了不同的kernel切分，导致次优调度
- MobileNet无明显变化：depthwise卷积的shape信息补全对编译器决策影响小
- **教训**: 给ATC"更多信息"不一定帮助它--有时反而会干扰它的默认优化路径

### 3. onnxsim / onnxoptimizer / opset13

**ONNX变化**: 仅 ir_version (6→7) 和 opset (11→13) 变化，**图结构完全相同**
**OM变化**: 大小与reexport_plain相同
**因果链**:
- 这些工具主要改变ONNX的"元信息"，不改变计算图拓扑
- 原始导出图已经比较干净（无BN、Identity等冗余），无额外节点可消除
- 性能差异(-3%~0%) 完全在噪声范围内，无统计学意义
- **结论**: 对当前导出链路，这些操作为无效操作

### 4. channels_last (MobileNet -3.00%, ResNet50 -0.08%)

**ONNX变化**: **字节级与原始ONNX完全相同**（MD5一致）
**OM变化**: 大小与reexport_plain相同（7.77MB），但MD5不同
**因果链**:
- PyTorch侧的`channels_last`布局信息在ONNX导出时**丢失了**
- ONNX文件与原始版本完全一样
- 但是ATC编译路径中输出文件名不同，导致OM元数据不同
- 性能差异(-3%~0%) 完全来自"第二次编译"的环境噪声，而非channels_last本身
- **结论**: 当前导出链路无法传递layout信息，此为无效操作

### 5. bn_folded (MobileNet -2.32%, ResNet50 +0.79%)

**MobileNet的ONNX变化**: 无变化（图中BN已为0，无可折叠的BN）
**ResNet50的ONNX变化**: 节点数122→90，ReLU 49→17
**ResNet50的数值验证**: **严重失真**（max_abs_diff=6.5亿, cosine=-0.099）
**因果链**:
- MobileNet: ONNX已无显式BN，folding无效 → 性能无变化（预期内）
- ResNet50: folding破坏了数值正确性 → 性能差异不可解释
- **结论**: bn_folded是失败的优化，MobileNet上无效果，ResNet50上不可信

---

## 总体结论

1. **fp16 是唯一在当前平台上经严格验证有效的优化**
   - MobileNet: -10.51% (p=0.024, 超过噪声基底)
   - ResNet50: -1.05% (p=0.030, 刚过噪声基底)
   - 效果差异合理：轻量网络对带宽更敏感

2. **其他所有前端改图优化无效**
   - 因为它们的ONNX图结构与原始几乎一样
   - 表观差异（-3%~0%）在噪声范围内
   - 这些工具在没有可清理的冗余时无能为力

3. **shape_inferred 在ResNet50上反而显著变慢（-1.79%）**
   - 这是唯一一个"有害"的优化
   - 可能的机制：shape信息改变了ATC的kernel选择

4. **噪声基底已被充分标定**
   - MobileNet: between-run std=1.18%
   - ResNet50: between-run std=1.23%
   - 可检测的最小效应量约1.2%
   - 在这个精度下，fp16效果是可靠的
