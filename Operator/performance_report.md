## 3. 对比分析

### 3.1 性能对比

| 模型 | 延迟 | 吞吐量 | 加速比 |
|------|------|--------|--------|
| MobileNetV3-Small | 0.97 ms | 1030 FPS | 3.9x |
| ResNet50 | 3.81 ms | 262 FPS | 1x |

### 3.2 单元利用率对比

| 单元 | MobileNetV3 | ResNet50 | 说明 |
|------|-------------|----------|------|
| Cube/MAC | 14.1% | 48.9% | ResNet50 更充分利用 |
| Vector | 22.4% | 2.3% | MobileNet 逐元素运算更多 |
| Memory/MTE | 56.2% | 97.4% | **两者都是内存瓶颈** |

### 3.3 瓶颈分析

```
┌─────────────────────────────────────────────────────────────────────┐
```

## 4. 优化建议

### 4.1 通用优化

1. **算子融合**: 将相邻的 Conv+BN+ReLU 融合为单个算子
2. **内存优化**: 调整 tiling 策略，提高 L1/L2 Cache 命中率
3. **量化**: 使用 INT8 量化可减少内存带宽压力

### 4.2 模型特定优化

| 模型 | 主要问题 | 优化方向 |
|------|---------|---------|
| MobileNetV3 | Memory 56% | DWConv 融合优化 |
| ResNet50 | Memory 97% | 更激进的残差融合 |
